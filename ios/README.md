# Read Later · iPhone 应用

用途：在微信等任何应用里，**不离开当前应用、不打开 Read Later**，一键把链接存进阅读库；电脑插件和网页马上能看到。

## 工作方式

1. 应用里提供一个"保存到 Read Later"动作（App Intent），在后台运行，不会把你带离微信。
2. 你在“快捷指令”里建一个只有一个动作的快捷指令，内容选“剪贴板”，再把它放进控制中心（iOS 18 或更高）。
3. 微信：文章右上角 “…” → 复制链接 → 下拉控制中心点一下按钮 → 弹出“已保存：标题”。
4. 应用用手机自己的网络下载网页，取标题和正文；再向云端阅读库追加一条记录，格式与电脑插件完全一致，所以其他设备同步后直接显示。

## 安装到手机

需要 Mac 和 Xcode，以及你的开发者账号。

1. 用 Xcode 打开 `ios/ReadLater.xcodeproj`。
2. 选择 ReadLater 这个 target → Signing & Capabilities，确认 Team 是你的开发者团队（项目里已预填；Bundle ID 为 `com.onevalar.readlater`，可改）。
3. 手机用数据线连接并信任电脑，选择你的手机，点 Run。
4. 手机上第一次需要在 设置 → 通用 → VPN 与设备管理 里信任开发者。
5. 打开应用，用阅读库账号登录（与电脑、网页相同的邮箱密码）。
6. 按应用里“设置控制中心按钮”的 4 步做一次。

## 修改工程

工程由 `project.yml` 生成：

```sh
cd ios
xcodegen generate
xcodebuild -project ReadLater.xcodeproj -scheme ReadLater -destination 'platform=iOS Simulator,name=iPhone 16 Pro' CODE_SIGNING_ALLOWED=NO test
```

## 已做的验证

- 22 项单元测试：链接识别、微信文章解析、验证页识别、登录刷新与重试、查重、云端读回确认、阅读库还原（新增/改动/删除）、离线改动保留、换账号不串数据。
- 生成的记录与网页端校验器逐字节一致（用网页端同一套 `validateOperation`/`serializeOperation` 检查过）。
- 模拟器里能启动，动作已注册，openAppWhenRun 为 false。

## 还没验证（必须在真机上试）

1. 快捷指令里选“剪贴板”作为内容后，运行时会不会弹“允许粘贴”的授权框。
2. 手机上直接下载微信文章，能不能拿到正文；遇到“环境异常”验证页时会只存链接，标题用链接代替，之后可补。
3. 在微信里下拉控制中心点按钮，微信是否保持在前台。
4. 从云端同步回电脑插件、网页的完整往返。

## 已知限制

- 应用使用 iOS 26 的 Liquid Glass 原生控件，最低需要 iOS 26；控制中心放快捷指令需要 iOS 18 或更高。
- 应用只有一个主页面：阅读库（待读 / 已读、搜索、标已读、删除、文章阅读页）；登录和控制中心设置都在右上角“设置”里。
- 本机保留一份完整副本，离线也能看和标已读，联网后自动同步；还没做阅读进度记录。
- 暂未做分享菜单扩展和 Safari 插件。
